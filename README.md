# Taster-Rad (Prototyp)

Tastergesteuertes Zufallsrad für den Unterricht, nutzbar am iPad per Touch oder mit einem Taster
(Kabel-Adapter oder Bluetooth, meldet sich als Tastatur). Läuft nach dem ersten Öffnen offline.
Eigene Vorlagen und Bilder bleiben auf dem Gerät.

**Aufs iPad:** Seite in Safari öffnen, „Teilen → Zum Home-Bildschirm“, einmal mit Internet öffnen
und auf „Bereit für offline.“ warten.

**Bei Änderungen:** Versionsnummer in `sw.js` erhöhen.
